How to use it

  1. Open the user menu (your profile picture, top right) and choose Theme Editor, or use the button above.
  2. Change options on the right. The preview and the page behind update live.
  3. Try a Preset, search options, or click Changed only to review your edits.
  4. Click Save & Reload. The theme applies to everyone.

Safety net

  • Close without saving discards everything (you'll be asked first).
  • Undo / Redo (Ctrl+Z / Ctrl+Y) while editing.
  • Previous save brings back the theme from before your last save.
  • Export gives you a code to back up or share; Import restores it.
What you can change

Colours & background

Accent, page and menu colours, true OLED black, an accent that matches each title's artwork, a background image or soft accent glow, and frosted-glass menus.

Top bar

Colour, opacity and blur, your own logo, transparent until you scroll, and hiding the search, cast or SyncPlay icons.

Cards & posters

Corner radius (separately for wide tiles), spacing, hover zoom or glow, borders, shadows, dimmed watched items, badge and progress-bar colours, title styling.

Details pages

Banner darkness and blur, title size, accent or solid Play buttons, and hiding any button, line or section (cast, similar, extras…).

Home, lists & player

Home row titles and spacing, the My Media row, episode descriptions and thumbnail size, player accent colours and subtitle style and size.

Login, night mode & users

Login background, blur, logo and welcome text; automatic dimming at night; and optional personal themes each user can pick from their menu (My Theme).

Good to know
How the theme reaches every device

In browsers, the plugin adds the theme and the editor to the web client through the File Transformation plugin (required). Saving also writes the theme into a marked block at the top of Dashboard > General > Custom CSS, because the TV apps (Samsung Tizen, LG webOS) carry their own copy of the web client and only receive Custom CSS. Anything else you keep in Custom CSS is left untouched.

After a plugin update, the saved theme and the Custom CSS copy are rebuilt automatically the first time an administrator opens the web client, so new fixes reach the TV apps too.

TV and mobile apps
  • TV apps show the theme (from Custom CSS) but not the editor, the personal themes, night mode or the per-title accent, which need the browser script.
  • On TVs there is no mouse: the hover glow appears as a ring on the focused card instead.
  • The Android/iOS apps use the web client, so the theme applies there as in a browser.
  • A few options use the :has() CSS feature (Chrome 105+). Older TV browsers simply skip those.
Troubleshooting
  • No "Theme Editor" in the menu: it's for administrators only. Check the status above: "Theme added to the web client" must be green. If not, make sure File Transformation is installed and enabled, then restart Jellyfin.
  • Changes don't show: clear the browser's site data for Jellyfin (F12 > Application > Clear site data) and reload.
  • A page looks blank or broken: open the Theme Editor and click Diagnostics. It checks the page scripts aren't damaged and that everything is up to date.
  • TV looks different to the browser: open the editor and click Save & Reload to refresh the Custom CSS copy.
  • Start over: in the editor click Reset, then Save & Reload.
